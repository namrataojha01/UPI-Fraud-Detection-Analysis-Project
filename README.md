Data Analytics Project — UPI Fraud Detection & Payment Risk Intelligence

Worked with a dataset of 26,393 UPI transactions where I built a complete end-to-end analytics solution to detect fraud patterns and assess payment risk.

𝗪𝗵𝗮𝘁 𝗜 𝗯𝘂𝗶𝗹𝘁: 𝗣𝘆𝘁𝗵𝗼𝗻 | Jupyter Notebook - Cleaned & processed 26,393 transaction records - Feature Engineering — Risk Scoring, Amount Bands, Time Slots, Flag Analysis - EDA using Pandas, Matplotlib & Seaborn

𝗠𝘆𝗦𝗤𝗟 | 12 Business Queries - Fraud segmentation & merchant analysis - State-wise & time-based fraud patterns - High-risk transaction identification

𝗣𝗼𝘄𝗲𝗿 𝗕𝗜 | Interactive Dashboard - 3-page dynamic dashboard - DAX measures for KPIs & advanced metrics - Slicers, bookmark navigation & drill-through
